# InnoDocApp no AuthZ

This repository contains the setup of InnoDocApp to test performance without authorization. 

For further details, see the detailed [InnoDocApp documentation](../innodocappauthzenv1.0-main/README.md).

The application can be started via docker compose with a single command:

```
docker compose up --build -d
```

The API will be available at `http://127.0.0.1:5000`.
